# Sécurité

Cette plateforme est en développement. Consultez `docs/implementation-status.md` avant tout usage avec des données réelles.

Pour signaler confidentiellement une vulnérabilité, utilisez le signalement privé GitHub du dépôt lorsqu’il est activé, ou contactez Mopacy depuis https://mopacy.be. N’incluez jamais de secrets, données clients ou preuves sensibles dans une issue publique.

Les corrections de sécurité doivent inclure un scénario de reproduction et un test de non-régression approprié. Les dépendances et images doivent être auditées avant chaque livraison de production.

# Modèle de licence

Le noyau PAM-olive est open source sous AGPL-3.0-or-later. Il doit rester utilisable et auditable sans licence commerciale.

Les modules suivent l’un de ces deux modèles, annoncé dans leur manifeste et dans leur dépôt :

1. **Communautaire** : même licence AGPL que le noyau ;
2. **Commercial** : contrat de licence distinct, code et distribution gérés séparément.

Une clé de licence peut contrôler l’accès à une extension commerciale, mais elle ne constitue pas une protection du code open source. La valeur d’un module commercial doit être portée par ses droits de distribution, les mises à jour signées, le support et les services associés. Cette règle évite de promettre une impossibilité technique qui n’existe pas dans un produit open source.

# Read-only qualification preflight

This subset observes a fresh dedicated GitHub-hosted Linux runner. It does not
activate the origin receiver, its privileged setup, an egress policy, material
approval, image qualification or deployment.

The version measurement acknowledges the existing provider's public software as
a supplier trust base. Fixed version calls include `sudo --version`; they are
observations, not prior admission of the measured executables. Binary bytes,
metadata and versions must remain stable. Missing tools, aliases or an expired
work budget refuse without retries or installation. The owner horizon is 120
seconds, with 90 seconds of work and a 30-second reserve. Results remain
UNAPPROVED. A future policy inspection requires independently commissioned
source and tool pins before its single read-only `sudo nft` call; that mode is
not activated by this delivery.

The separate public parent observer reads only metadata of the fixed dpkg-query
and Chrome paths through directory FD anchors. It never reads file contents,
follows aliases, launches programs or changes ownership, modes or ACLs. The
observation has its own 30-second deadline and fixed exclusive output. Provider
labels are not attestations; a new observation cannot establish the historical
cause of another job. Writable or unavailable parents do not authorize repair.
Receipt requires normal process completion and bounded valid JSON; a partial
output file is not evidence of success.

The source omits the empty top-level `qualification/__init__.py` deliberately:
Python namespace imports work while the project's existing Django test discovery
remains unchanged. The explicit pure runner executes ten preflight and four
parent-observer tests with socket, subprocess, ctypes and SQL calls forbidden.
Eight original runtime/test sources, including the shared bounded IO helper,
remain byte-exact. Only the runner adds the other test suite.

The publisher commits the source and its exact hash manifest first. A subsequent
workflow revision checks out that immutable source commit and verifies the
manifest before execution. Observed values never update an admitted profile
automatically. The complete B2 implementation is reviewed and qualified
separately; these observations do not qualify its networking or privilege model.
